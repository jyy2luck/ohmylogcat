## Context

当前快捷键处理集中在 `src/app.rs` 的主界面、查找栏和弹窗事件分发中，大部分分支直接比较 `KeyCode::Char('x')`。文本字段则通过 `TextInput` 接收原始 `KeyEvent`，必须保留用户输入的大小写。`n` 和 `N` 已经是两个有意区分的查找导航快捷键，分别表示下一个和上一个结果。

## Goals / Non-Goals

**Goals:**

- 在所有动作快捷键分发层支持 ASCII 字母的大小写等价匹配。
- 让 `Shift` 产生的大写字符和 `Caps Lock` 产生的大写字符都能触发对应动作。
- 保留 `n` / `N` 的查找方向区别、现有修饰键限制以及非字母快捷键行为。
- 确保文本输入路径继续使用原始字符，不被快捷键兼容逻辑修改。
- 为主界面、查找栏、选择复制和弹窗分支提供可回归验证的测试覆盖。

**Non-Goals:**

- 不引入可配置快捷键。
- 不改变快捷键显示文字或非字母快捷键。
- 不把查找、筛选、导出路径或设置字段中的文本统一转换为小写。
- 不重新设计 `n` / `N` 的导航交互。

## Decisions

### 1. 在动作分发层增加大小写无关的字符匹配辅助函数

**选择：** 增加一个只比较 ASCII 字母的快捷键辅助函数，接收原始 `KeyEvent` 和期望的快捷键字符，只有当事件为 `KeyCode::Char` 且字符与期望字符大小写无关地相等时才返回匹配。各动作分支继续单独检查已有的修饰键条件。

**理由：** 该方式能统一覆盖主界面和弹窗，避免在每个分支重复写 `x/X`，同时不会改写传给文本输入的字符。只比较 ASCII 字母可以避免把非快捷键的 Unicode 文本字符错误当成快捷键。

**备选方案：** 在事件入口把所有字符转成小写再分发。放弃，因为这会改变文本输入、筛选词和导出路径的用户内容。

**备选方案：** 在每个 `match` 分支中手写小写和大写两个模式。放弃，因为分支数量多，后续新增快捷键容易遗漏大小写分支。

### 2. 保留 `n` / `N` 的原始大小写分支

**选择：** 查找结果导航继续直接区分小写 `n` 和大写 `N`，不经过大小写无关辅助函数。其他没有大小写复用语义的字母快捷键使用辅助函数。

**理由：** `n` / `N` 当前承担相反方向的动作。将二者合并会破坏已有的上一项导航；保留原始分支可以满足新增兼容行为而不改变既有操作含义。

**备选方案：** 让 `n` / `N` 都执行下一项，再重新分配上一项快捷键。放弃，因为这会造成现有用户行为和文档的破坏性变化。

### 3. 文本输入继续接收原始按键

**选择：** `TextInput::handle_key`、查找输入、筛选输入、导出路径和设置字段不调用快捷键匹配辅助函数；只有当前焦点允许动作快捷键时才进行快捷键判断。

**理由：** 文本输入中的 `C`、`F`、`R` 等字符必须作为内容插入，而不是被解释为主界面或弹窗动作。该边界也保持筛选和路径的大小写内容不变。

### 4. 用分层测试验证行为边界

**选择：** 在快捷键分发测试中覆盖主界面、查找、设备/导出/设置等弹窗，以及 `n` / `N` 的方向区别；在 `TextInput` 测试中验证大写字符原样插入。README 的快捷键表增加大小写规则说明。

**理由：** 大小写支持是跨多个焦点层的行为变化，仅测试单个辅助函数无法证明动作分发和文本输入边界正确。

## Risks / Trade-offs

- **[Risk] 不同终端可能把 Shift 大写字符报告为大写字符或小写字符加 `SHIFT` 修饰符。** → **Mitigation:** 辅助函数比较 `KeyCode::Char` 的 ASCII 字母时忽略大小写，同时不依赖字符是否带 `SHIFT`。
- **[Risk] 新增快捷键分支可能意外抢走文本输入字符。** → **Mitigation:** 只在非文本动作分发路径使用辅助函数，并增加筛选、查找和路径输入测试。
- **[Risk] `n` / `N` 的特殊规则容易在后续重构中被统一匹配覆盖。** → **Mitigation:** 将其作为显式测试场景和设计约束，测试小写 `n` 为下一项、大写 `N` 为上一项。
- **[Risk] 大小写兼容可能扩大带修饰键事件的匹配范围。** → **Mitigation:** 辅助函数不改变修饰键判断；每个动作沿用现有的 `Ctrl`、`Cmd`、`Super` 和 `Meta` 限制。

## Migration Plan

无需数据迁移或配置迁移。这是纯交互行为变更；发布后用户可以继续使用原有小写快捷键，也可以使用符合规则的大写形式。若需要回滚，只需回退快捷键辅助匹配及其测试和文档变更。
